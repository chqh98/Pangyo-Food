# 판교 회식 추천 🍻

인원 · 1인 예산 · 음식 종류 · 위치 · 분위기 · 룸/주차 조건을 입력하면 판교 회식 장소를 점수순으로 추천해 주는 웹 앱입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 추천 로직 테스트
npm run build    # 프로덕션 빌드
```

## 기능

- 조건 필터: 인원(최대 수용 인원), 1인 예산(20% 초과까지 감점 후 노출), 음식 종류, 위치, 룸/주차 필수
- 추천 점수(0~100): 예산 적합도, 분위기 일치, 판교역 접근성, 단체 룸 여부, 좌석 여유
- 추천 이유 표시 (예: "예산 안에 들어와요", "판교역 도보 4분")
- 🎲 랜덤 선택: 상위 5곳 중 하나를 뽑아 줌
- 즐겨찾기 (브라우저 localStorage)

## 구조

```
src/
  types.ts              타입, 음식 종류/지역/분위기 목록
  data/restaurants.ts   가게 데이터 (현재 샘플)
  lib/recommend.ts      필터링 + 점수 계산 로직
  App.tsx               UI
```
